# Cite This Tool

If you use NourishScope in a report, grant application or publication, please cite the version you used. The version number is in the footer of every page and on every planning brief.

## Suggested citation

Olaogun, Y. K. (2026). *NourishScope: A decision-support tool for community nutrition programs* (Version 1.0.0; Methodology 1.0) [Computer software]. https://nourishscope.app/

## Data

Please also credit the original data publishers listed on the [Data Sources](/data-sources) page. The compiled Kentucky county dataset is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
